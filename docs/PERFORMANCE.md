# 性能说明

在同一台 Windows 机器上，使用 Python 3.12，生成黄牌双层“云AH5198”，开启立体效果，强度 0.7，导出 PNG。

7680 × 3840 测试：优化前峰值进程树工作集约 379 MiB，优化后约 309 MiB，减少约 18%。
内存采样间隔 25 毫秒，包含 Python 虚拟环境启动器及子进程；结果为单次测量，不能视为所有电脑的保证。
分块混合前后图像比较最大差异为 1 个 8 位色阶。

EXE 文件从 76,198,803 字节减至 67,793,149 字节，减少约 11%。
主要措施：移除冗余 RGB 副本、仅保存外框条带、分块混合浮点光照、精简打包模块，并使用满足本项目需求的 OpenCV 4.10。
运行依赖采用各自许可证，详情见 THIRD_PARTY_NOTICES.md。

16K 图片仍需较多内存；文件体积、解包后体积、空闲内存和导出峰值内存是不同指标。
本项目已验证 16000 × 8000 PNG 导出，不承诺在所有硬件配置上达到相同速度或内存使用量。
